# Resume Analyzer - ATS Checker

A Django web application that analyzes resumes for ATS (Applicant Tracking System) compatibility.

## What it does
- User pastes resume text
- System checks for important keywords
- Shows ATS score as percentage
- Lists missing skills to improve

## Tech Stack
- Python
- Django
- HTML/CSS

## How to Run
1. Clone the repo
2. Install Django: `pip install django`
3. Run: `python manage.py runserver`
4. Open: `http://127.0.0.1:8000`
